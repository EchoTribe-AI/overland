03

Jake's two open calls

Everything else above is agreed or mechanical. These two are reader-experience trades that deserve an explicit decision:

1 · Allow 300×250 in the mobile forum bucket?

The taller unit pays meaningfully better than 320×50 banners, but it takes more of the reading flow between posts — the very thing the community complained about.

Recommendation: launch without it (320×50 + 320×100 only). Add 300×250 in a second phase only if complaint volume stays at zero for a month. Cheap to add later; expensive to walk back.

2 · One sticky bottom anchor on mobile instead of stacked units?

A single anchored unit has the highest viewability by design and could replace several stacked ones — but it's the format category you've been consistent about disliking.

Recommendation: skip it for now. Ship the in-content + cap changes first; revisit only if Safari/mobile eCPM hasn't moved after two measured weeks. Keeping this in reserve is also useful — it's the concession NM will ask for, and it's better traded than given.

The position this gives us

We can plausibly return to — and pass — the historical peak without a single high-impact format: no interstitials, no floating video, no units between forum posts, no mobile sticky anchor. That's the answer when NM pushes "higher impact formats": the recovery is already funded by fixing what broke and configuring mobile properly. The mobile repair is the quiet multiplier — it raises the viewability that every buyer prices against, on the 56% of the audience currently earning the least.
